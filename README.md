# ELMO User API TypeScript SDK

TypeScript and JavaScript client for the ELMO User API (API version `v1-rc3`). It uses
the [Fetch API](https://fetch.spec.whatwg.org/).

## Prerequisites

- ELMO API credentials: a client ID and a client secret. A Company Admin creates and manages API credentials in ELMO.
- Node.js 18 or later (global `fetch`), or a browser. For an older runtime, install a `fetch` polyfill.

## Install

```bash
npm install @elmo-software/user-api-sdk@0.1.1
```

## Configure

`ElmoClient` needs your client ID and client secret only. It gets the OAuth2 access token
(client-credentials grant, `POST /oauth/token`) on the first request, and gets a new token
60 seconds before the current token expires. Parallel first calls share one token request.
You do not send a token yourself.

```ts
import { ElmoClient, ResponseError } from '@elmo-software/user-api-sdk';

const elmo = new ElmoClient(process.env.ELMO_CLIENT_ID!, process.env.ELMO_CLIENT_SECRET!);

try {
  const users = await elmo.users.getUserCollection({ itemsPerPage: 10 });
  for (const user of users) {
    console.log(user.id, user.firstName, user.lastName);
  }
} catch (e) {
  if (!(e instanceof ResponseError)) throw e;
  console.error(`HTTP ${e.response.status}: ${await e.response.text()}`);
}
```

Keep the client secret out of source control and out of browser bundles. Read it from the
environment or a secret store, and call the API from a server.

Optional third constructor argument:

| Argument | Default | Use |
|---|---|---|
| `basePath` | `https://api.elmotalent.com.au` | The ELMO API host for your environment. |

```ts
const elmo = new ElmoClient(clientId, clientSecret, 'https://your-elmo-api-host');
```
